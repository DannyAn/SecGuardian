# OWASP ASVS 认证与会话管理映射

本文档映射 OWASP Application Security Verification Standard (ASVS) 4.0.3 中与认证和会话管理相关的验证要求。

## V2: 认证验证

### V2.1 密码安全

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 2.1.1 | 密码最小长度 ≥ 8 字符 | L1 | 检查注册/修改密码的长度校验逻辑 |
| 2.1.2 | 密码最大长度 ≥ 64 字符 | L1 | 检查是否错误限制了最大长度（如 < 64） |
| 2.1.3 | 密码不截断 | L1 | 检查 Unicode 处理和 trim 操作 |
| 2.1.4 | 允许所有可打印 Unicode 字符 | L1 | 检查字符过滤逻辑 |
| 2.1.5 | 可修改密码（需验证当前密码） | L1 | 检查修改密码接口是否要求旧密码 |
| 2.1.7 | 密码强度检查 | L1 | 检查是否验证密码不在 breached password 列表中 |
| 2.1.9 | 密码 pasting 不被阻止 | L1 | 检查 password 字段是否允许 paste |
| 2.1.10 | 无密码提示 | L1 | 检查是否存在密码提示/安全问题 |

### V2.2 通用认证

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 2.2.1 | 抵御自动化攻击（速率限制） | L1 | 检查登录/注册/密码重置接口的 rate limit |
| 2.2.2 | 弱认证器不被使用 | L1 | 检查是否使用 NIST SP 800-63B 定义的弱认证器 |
| 2.2.3 | 邮件/短信通知安全事件 | L1 | 检查登录通知、设备变更通知 |
| 2.2.4 | 支持 MFA（防钓鱼） | L2 | 检查 MFA 实现 |

### V2.3 认证器的生命周期

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 2.3.1 | 初始密码/令牌唯一且强制修改 | L1 | 检查首次登录流程 |
| 2.3.2 | 注册/激活前验证身份 | L1 | 检查邮件/短信验证流程 |

### V2.4 凭证存储

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 2.4.1 | 密码使用自适应哈希存储 | L1 | 检查是否使用 bcrypt/scrypt/PBKDF2/argon2 |
| 2.4.2 | 盐值唯一且随机 | L1 | 检查哈希实现是否生成随机盐 |
| 2.4.3 | 不使用 MD5/SHA-1 存储密码 | L1 | grep MessageDigest.getInstance( |
| 2.4.4 | 密码迁移到更强算法 | L2 | 检查是否有密码哈希升级策略 |

### V2.5 凭证恢复

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 2.5.1 | 密码重置不发送明文密码 | L1 | 检查重置邮件/短信内容 |
| 2.5.2 | 密码重置 Token 一次性使用 | L1 | 检查重置后 Token 是否失效 |
| 2.5.3 | 重置 Token 在 15 分钟内过期 | L1 | 检查 Token 创建时间戳验证 |
| 2.5.4 | 重置 Token 安全随机 | L1 | 检查随机数生成器 |
| 2.5.5 | 重置 Token 不与账户绑定存储 | L2 | 检查数据库存储方式 |
| 2.5.6 | 重置后通知用户 | L2 | 检查是否有通知机制 |

## V3: 会话管理

### V3.1 基础会话管理

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 3.1.1 | 会话 Token 永不暴露在 URL | L1 | grep session.*URL / JSessionID 在 URL |
| 3.1.2 | 会话 Token 高熵（≥ 128 bit） | L1 | 检查会话 ID 生成算法 |
| 3.2.1 | 登录后生成新的会话 Token | L1 | 检查登录前后 session ID 是否变化 |
| 3.2.2 | 会话 Token 使用通用框架生成 | L1 | 检查是否为自定义 session 生成逻辑 |
| 3.2.3 | 会话可被主动终止（登出） | L1 | 检查登出是否清除服务端 session |
| 3.2.4 | 空闲超时 ≤ 30min | L2 | 检查 session timeout 配置 |
| 3.3.1 | 登出后所有会话 Token 失效 | L1 | 检查退出是否结束所有活跃 session |
| 3.3.2 | 可通过接口查看/终止活跃会话 | L2 | 检查用户会话管理界面 |

| 3.4.3 | Cookie 设置 SameSite 属性 | L1 | 检查 SameSite 配置 |
| 3.4.4 | Cookie 设置 __Host- 前缀 | L2 | 检查是否需要 __Host- 前缀 |

### V3.5 Token 安全

| ASVS | 要求 | Level | 检查方法 |
|------|------|-------|---------|
| 3.5.1 | Token 允许撤销 | L1 | 检查 JWT 撤销机制 |
| 3.5.2 | Token 签名算法限制 | L1 | 检查 JWT verify 时允许的算法白名单 |
| 3.5.3 | 无状态 Token 使用数字签名 | L1 | 检查 JWT 是否正确验证签名 |

## 审计优先级

按 Level 优先级检查：
1. **L1 要求** → 所有应用必须满足（CWE Top 25 的基础防护）
2. **L2 要求** → 处理敏感数据的应用必须满足
3. **L3 要求** → 高价值目标（银行、政府、医疗）

在审计报告中标注不满足的 ASVS 条目编号，方便开发团队对照修复。
