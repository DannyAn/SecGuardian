# 信任边界分析 (Trust Boundary Analysis)

## 分析方法概述

信任边界是系统中"可信区域"和"不可信区域"的分界线。每当数据或控制流跨越信任边界时，必须经过安全验证。

核心问题：**系统假设什么是可信的？这个假设是否成立？**

## 分析流程

### Phase 1: 信任边界识别

从架构图中识别所有信任边界：

```
常见的信任边界:

网络边界:
  Internet ←→ DMZ ←→ 内网 ←→ 数据库网络
  
进程边界:
  用户进程 ←→ 特权进程 (如 setuid、sudo)
  应用进程 ←→ Sidecar 代理
  
用户态/内核态:
  应用 ←→ 内核 (系统调用)
  应用 ←→ eBPF 程序
  
租户边界 (多租户系统):
  租户 A 数据 ←→ 租户 B 数据
  租户容器 ←→ 宿主机
  
服务边界:
  微服务 A ←→ 微服务 B (即使在同一集群内)
  HTTP ←→ gRPC ←→ 消息队列
  
硬件边界:
  应用 ←→ TEE/HSM/Enclave (SGX/SEV)
  主机 ←→ USB/外设
```

### Phase 2: 跨边界交互审计

对每个跨越信任边界的交互，检查是否执行了适当的验证：

| 边界类型 | 必须的安全控制 |
|---------|-------------|
| 外部网络 → 内部服务 | 认证 + 授权 + 输入验证 + 速率限制 + TLS |
| 微服务 A → 微服务 B | mTLS + 服务间认证 + 输入验证 |
| 普通用户 → 管理员 API | 角色检查 + 审计日志 |
| 应用 → 数据库 | 最小权限账号 + 参数化查询 |
| 租户 A → 租户 B 数据 | 租户隔离验证（查询中强制 tenant_id） |
| 用户态 → 内核态 | 权限检查 (capabilities, seccomp) |
| CI/CD → 生产环境 | 审批 + 审计 + Secret 隔离 |

### Phase 3: 信任假设挑战

对系统设计中每个"我相信 X 是安全的"的假设，提出挑战性问题：

```
□ "内部网络是安全的" → 内部员工恶意行为？内网被渗透？供应链攻击？
□ "这个微服务只被我们的前端调用" → API Key 被泄露？内部横移？
□ "这个接口速率有限" → 分布式请求？不同账户轮流请求？
□ "文件上传经过了前端校验" → 直接 curl 请求后端 API？
□ "数据库只有应用能访问" → SQL 注入绕过了应用层控制？
□ "K8s Pod 之间是隔离的" → 容器逃逸？共享内核？
□ "这条消息队列的消息是可信的" → 生产者是否可能被攻破？
```

### Phase 4: 边界渗透场景

对每个信任边界，构建可能的渗透路径：

```
边界: 前端 Web ←→ 后端 API

信任假设: 前端已做输入校验，后端可以直接用

渗透路径:
1. Burp Suite 拦截请求，绕过前端校验，发送恶意 payload
2. 直接 curl 调用后端 API（API 未做认证）
3. GraphQL 端点允许任意查询（introspection enabled）
4. CORS 配置不当导致跨域请求

发现的弱点:
- POST /api/upload 信任前端已校验文件类型 → 可上传 webshell
- GET /api/users 未做分页 → 可一次拉取全部用户数据
```

### Phase 5: 输出

```markdown
## 信任边界分析报告

### 架构信任边界图
Internet → [WAF] → [API Gateway] → [微服务] → [数据库]
                         ↓
                    [外部支付服务] (第三方)

### 信任假设审计

| 边界 | 信任假设 | 验证结果 | 风险 |
|------|---------|---------|------|
| WAF → API Gateway | WAF 已过滤 SQL 注入 | ⚠ API Gateway 未再做校验 | High |
| API Gateway → 微服务 | 内网通信安全 | ⚠ 服务间无 mTLS | Medium |
| 微服务 → 支付服务 | 支付回调签名验证 | ✓ HMAC 签名验证正确 | OK |

### 发现清单

#### [H-01] 后端信任前端校验
- 边界: 前端 ←→ API
- 信任假设: 文件类型由前端校验
- 验证: POST /api/upload 未检查 Content-Type 和文件魔数
- 风险: 可上传 .jsp/.php webshell
- 修复: 后端独立校验文件类型和内容
```
