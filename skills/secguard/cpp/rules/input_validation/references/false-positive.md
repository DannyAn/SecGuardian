# 输入验证误报抑制策略

## 判定决策树

```
检测到疑似输入验证缺失
│
├─ 输入来源是否真的不可信？
│  ├─ 编译期常量 / 内部硬编码 → 抑制（非外部输入）
│  ├─ 同级可信模块内部传递 → 抑制（内部边界）
│  ├─ 配置文件（root 只写路径）→ 抑制（受控环境）
│  └─ 外部输入（网络/用户/环境变量）→ 继续
│
├─ 是否已有隐式验证？
│  ├─ 上游调用者已验证（同翻译单元、明确验证函数）→ 抑制
│  ├─ 白名单枚举映射（仅返回已知安全值）→ 抑制
│  ├─ 上游网关/WAF 过滤 → 抑制（需确认配置文件存在）
│  └─ 否: 继续
│
├─ 是否为格式化输出场景？
│  ├─ printf("%s", user_input) → 抑制（%s 是安全的）
│  ├─ printf(user_input) → **报告**（格式字符串漏洞 CWE-134）
│  ├─ snprintf(buf, n, "%s", input) → 抑制（安全格式化 + 截断）
│  └─ snprintf(buf, n, input, ...) → **报告**（格式字符串作为可变参数）
│
├─ 路径使用是否安全？
│  ├─ 使用 realpath() 解析后再使用 → 抑制（符号链接已消解）
│  ├─ open() + O_NOFOLLOW → 抑制（禁止符号链接跟随）
│  ├─ 符号链接 TOCTOU 已通过 fstat/stat 比对 inode 处理 → 抑制
│  ├─ 仅基于字符串检查 ../  → **报告**（不充分，缺少 realpath）
│  └─ 无任何路径消毒 → **报告**
│
├─ 数值类型安全？
│  ├─ 通过枚举/位掩码约束范围 → 抑制
│  ├─ atoi/atol 无溢出检查 → **报告**（CWE-190）
│  ├─ strtol + 完整 endptr + errno 检查 → 抑制
│  └─ 否: 继续
│
└─ 默认: **报告** 为 CWE-20
```

## 抑制规则

1. **内部数据**: 变量值在函数内部构造，不来自外部 → 抑制
2. **配置重载**: 配置文件路径不可被普通用户修改 → 抑制
3. **数值参数范围已定**: 通过枚举或位掩码约束的数值 → 抑制
4. **截断安全**: snprintf 截断后使用 → 抑制（截断安全）

## 格式化字符串安全性判别

| 模式 | 判定 | CWE |
|------|------|-----|
| `printf("%s", input)` | 安全 — 格式字符串固定 | — |
| `printf(input)` | 漏洞 — 用户控制格式字符串 | CWE-134 |
| `fprintf(stderr, "%s", input)` | 安全 — 格式字符串固定 | — |
| `syslog(LOG_INFO, "%s", input)` | 安全 — 格式字符串固定 | — |
| `syslog(LOG_INFO, input)` | 漏洞 — 用户控制格式字符串 | CWE-134 |

## 路径遍历安全性判别

| 模式 | 判定 | 说明 |
|------|------|------|
| `realpath(input, resolved)` 后使用 `resolved` | 安全 | 符号链接已消解，`..` 已规范化 |
| `open(input, O_NOFOLLOW)` | 安全 | 禁止符号链接跟随 |
| `fstat(fd, &st1); stat(path, &st2); st1.st_ino == st2.st_ino` | 安全 | TOCTOU 已通过 inode 比对处理 |
| `strstr(input, "..")` 检查 | **不充分** | 路径编码可绕过 |
| 无任何检查 | **漏洞** | CWE-22 |

## 常见误报

1. **getenv("PATH") 用于 execvp**: execvp 利用 PATH 搜索可执行文件，非注入点
2. **getenv("HOME") 用于拼接日志路径**: 如果只有日志写入无安全隐患，抑制
3. **日志级别变量**: `int level = atoi(getenv("LOG_LEVEL"));` — 仅用于比较，非安全敏感
4. **调试信息**: `if (debug) { printf("%s\n", user_input); }` — debug 模式下的输出
