# 释放后使用跨函数追踪

## 规则

当 free 在函数 A 中完成，但指针解引用在函数 B 中、且 A 调用 B 时：

### 最大深度: 1 层

```c
void A() {
    free(p);
    B(p);  // B 接收已释放指针
}

void B(void *ptr) {
    ptr->field = 1;  // UAF
}
```

### 深度上限

超过 depth 1 的调用链 → 降级为 suspicious。

## 常见跨函数 UAF 模式

1. **回调函数**: 释放后注册的回调被调用，使用已释放上下文
2. **事件循环**: free(event) 后事件处理中的 event->data 解引用
3. **函数指针表**: 释放后函数表项仍可被调度调用
