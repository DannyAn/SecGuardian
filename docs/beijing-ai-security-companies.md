## 简历投递策略建议

### 差异化定位
投递时的核心卖点不是 "我会用 AI 做安全"，而是：

> **"我独立设计并实现了一个完整的 AI Agent 驱动的白盒代码安全审计系统，包括 tree-sitter 语义索引器（Go 实现）、67 个自包含安全检测器、17 项深度审计技能、SARIF 2.1.0 输出协议，并在 3 个 AI 平台上实现了部署。性能优化后 token 消耗降低 66%。"**

具体来说，面试时讲 3 个故事：
1. **架构设计能力**：为什么要把 AI 分析和报告渲染分离？怎么设计 findings-schema 协议的？
2. **安全攻防深度**：67 个检测器覆盖了哪些真实漏洞？CWETop25 覆盖率 68% 怎么验证的？
3. **工程落地能力**：3 平台部署的差异怎么处理的？性能瓶颈怎么定位和优化的？

### 推荐投递渠道（优先级排序）
1. **脉脉**：直接找到目标公司的安全团队负责人/CTO，私信 + 发项目链接
2. **Boss 直聘**：搜索"SAST"、"代码安全"、"AI安全"、"安全研发"关键词
3. **安全圈内推**：长亭/奇安信员工在安全圈活跃，找内推比海投效率高 10 倍
4. **官网投递**：最慢，但在脉脉上联系到人之后可以作为正式通道

### 建议准备的材料
1. SecGuardian GitHub 仓库（README 清晰展示架构和能力）
2. 一份 1 页中文简历，突出项目和量化结果
3. 一段 30 秒电梯演讲："我是安全+AI的全栈工程师，独立做了这套AI代码审计系统..."
